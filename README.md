# Граничне корисне навантаження квадрокоптера 22" — MATLAB-проєкт

Параметрична модель квадрокоптера X-схеми з пропелерами 22". Вона визначає максимально допустиме
корисне навантаження за 10 незалежними обмеженнями (механічними, енергетичними, тепловими,
експлуатаційними), оцінює невизначеність і автоматично генерує технічний звіт з оцінкою достовірності.

## Запуск

```matlab
>> cd quad_payload
>> main
```

Потрібен MATLAB (R2016b+) або GNU Octave ≥ 7. Toolbox-и не потрібні: використовуються лише
`fzero`, `eig`, `optimset` та базова графіка.

Результати з'являються в `results/`:
- `report.html` / `report.md` — технічний звіт;
- `fig1…fig8_*.png` — графіки;
- `results.mat` — усі дані.

Для фінального звіту збільште `cfg.N_mc` у `config.m` до 2000+. Час розрахунку зросте до кількох хвилин.

## Структура

```
main.m                    — точка входу
config.m                  — налаштування та пороги модуля достовірності
params/                   — вихідні дані з діапазонами і джерелами
  ref_params.m            — РЕФЕРЕНСНА конфігурація (редагувати тут)
  get_point.m             — номінальна / design-point (гірші умови)
  sample_params.m         — вибірка для Monte Carlo
models/                   — фізичні підмоделі
  motor_full_throttle.m   — повний газ (нелінійне рівняння, fzero)
  rotor_operating_point.m — робоча точка ротора при заданій тязі
  motor_thermal.m         — тепловий баланс з R(T) (fzero)
  arm_structure.m         — промінь: напруження, прогин, частота (аналітика)
  arm_fem.m               — промінь: МСЕ (верифікація)
  mass_inertia.m          — маса, ЦМ, тензор інерції
  equilibrium.m           — розподіл тяги (система рівнянь рівноваги)
  precompute.m            — величини, не залежні від навантаження
  eval_payload.m          — усі 10 обмежень при заданому m_p
  constraint_list.m       — перелік обмежень
solver/
  max_payload.m           — постановка і розв'язок задачі граничного навантаження
  monte_carlo.m           — поширення невизначеності
  sensitivity.m           — еластичності + торнадо
verify/
  units_check.m           — перевірка розмірностей формул
  convergence_study.m     — збіжність МСЕ та бісекції
  compare_methods.m       — аналітика vs МСЕ, C_P vs теорія імпульсу, бісекція vs fzero
credibility/
  credibility_check.m     — автоматичний модуль оцінювання достовірності
report/
  make_plots.m, generate_report.m
docs/MODEL.md             — математична документація, припущення, межі, план експериментів
```

## Конфігурації

Запуск: `main` (пресет із `config.m`), `main('heavy')` або `run_all` (обидві + `results/summary.md`). Результати лежать у `results/<пресет>/`.

`cfg.preset` у `config.m`:
- `'light'` (за замовчуванням) — реальні компоненти: мотор T-Motor U8 Lite KV150, пропелер P22×6.6, ESC Alpha 60A 12S, батарея Tattu Plus 12S 16000 мА·год, рама Tarot X4 (`params/real_params.m`).
- `'heavy'` — мотор T-Motor V605 KV210, пропелер V22×7.4, ESC FLAME 80A, посилені промені Ш35×2 (`params/real_params_heavy.m`).
- `'ref'` — узагальнена референсна конфігурація (таблиця нижче).

Перелік компонентів і джерела — `params/components.m` (розділ 1а звіту).

Варіанти компонування вантажу/батареї — `params/variants.m` (розділ 1б звіту).

## Очікувані результати (референсна конфігурація, `cfg.preset = 'ref'`)

Значення отримано незалежною реалізацією тієї ж моделі на Python. MATLAB-результати мають збігатися
з точністю до випадкової вибірки Monte Carlo.

| | Значення |
|---|---|
| Порожня маса | ≈ 12.8 кг |
| Макс. тяга ротора: нормальні / гірші умови | ≈ 9.5 / 8.4 кгс |
| m_p*, нормальні умови (ρ = 1.225, вантаж по центру) | ≈ 8.2 кг (запас тяги) |
| m_p*, гірші умови (ρ = 1.06, +40 °C, зміщення ЦМ 4 см) | ≈ 5.2 кг (запас тяги) |
| Monte Carlo, гірші умови: P5 / P50 / P95 | ≈ 2.6 / 4.4 / 6.2 кг |
| P(m_p* ≥ 8 кг) у гірших умовах | ≈ 0 % |

**Висновок:** 8 кг досяжні лише в нормальних умовах і за номінальних характеристик пропелера.
З урахуванням невизначеності C_T/C_P та умов експлуатації результат є **гіпотезою** до стендових випробувань.

## Як підставити реальні дані

У `params/ref_params.m` змініть `nom/lo/hi` параметра та встановіть `src = 'measured'`.
Модуль достовірності автоматично переведе залежні результати на вищий рівень доказовості.
