# Документація математичної моделі

## 1. Об'єкт і мета

Квадрокоптер X-схеми, 4 мотори, пропелери D = 22" (0.5588 м), батарея 12S.
Мета — знайти максимально допустиме **додаткове** корисне навантаження m_p*
за сукупністю механічних, енергетичних, теплових та експлуатаційних обмежень,
з оцінкою невизначеності та рівня доказовості результату.

Конкретної конструкції в ТЗ не задано, тому модель **параметрична**. Референсна конфігурація
(`params/ref_params.m`) відповідає типовому heavy-lift апарату 22"/12S і є **припущенням**.
Кожен параметр має джерело (`src`), яке модуль достовірності використовує для класифікації результатів.

## 2. Параметри системи

| Клас | Приклади | Роль |
|---|---|---|
| Незалежні — задані ТЗ / конструкцією | D, n_rot, L_arm, R_center, n_cells | фіксовані |
| Незалежні — з невизначеністю | C_T, C_P, Kv, Rm, R_th, E, σ_ult, k_joint, маси | вибірка Monte Carlo |
| Експлуатаційна огинаюча | ρ, T_amb, e_cg | гірший випадок |
| Критерії допустимості | k_TW, t_min, SF, θ_max, res_margin… | вимоги, погоджуються із замовником |
| Залежні | T_max, n, I, P, t, T_w, σ, δ, f_n, ЦМ, I | обчислюються |
| Шукана | m_p* | розв'язок задачі |

## 3. Підмоделі

### 3.1 Аеродинаміка ротора (статика)
T = C_T ρ n² D⁴,  Q = C_P ρ n² D⁵ / 2π,  P = Qω = C_P ρ n³ D⁵,
де n — оберти, об/с. Якість ротора FM = C_T^1.5 / (C_P √(π/2)).
Для порівняння використовується теорія імпульсу P = T^1.5 / (FM √(2ρA)).

### 3.2 Мотор (DC-модель BLDC)
Ke = Kt = 1/Kv [В·с/рад];  I = Q/Kt + I0;  V_m = Ke ω + I R_m.
Втрати: P_loss = I² R_m(T_w) + I0 V_m (мідь + залізо/тертя).

**Повний газ** — нелінійне рівняння (fzero):
Kt (I(ω) − I0) = C_P ρ (ω/2π)² D⁵ / 2π,  I(ω) = (V_oc − Ke ω)/(R_m + N R_pack/η_ESC).
Враховано просідання шини від струму всіх моторів. V_oc — напруга пакета БЕЗ навантаження в кінці місії (консервативно); просідання враховано лише через R_pack і R_esc (не двічі).

### 3.3 Тепловий режим
T_w = T_amb + R_th · P_loss(T_w),  R_m(T_w) = R_m25 (1 + α_Cu (T_w − 25)).
Розв'язується fzero. Якщо кореня немає, фіксується тепловий розгін.

### 3.4 Батарея
E_use = n_cells · V_nom · Q · 3600 · DoD · SoH;  t = E_use / P_bat;
P_bat = Σ P_elec,i / η_ESC + P_avionics.
Не враховано: залежність ємності від струму (Пейкерт) і температури, зміну напруги за розрядом.

### 3.5 Механічна рівновага (висіння)
Розподіл тяги між роторами — лінійна система:

```
Σ T_i = W
Σ y_i T_i = W y_cg      (крен)
Σ x_i T_i = W x_cg      (тангаж)
Σ s_i k_q T_i = 0       (рискання), k_q = C_P D / (2π C_T)
```

Зміщення вантажу e_cg задається вздовж діагоналі до ротора 1, бо для X-схеми це найгірший випадок.

### 3.6 Центр мас і моменти інерції
Апарат подано сукупністю тіл: центральний паралелепіпед, батарея, 4 точкові маси (мотор, пропелер, ½ ESC),
4 стрижні-промені та точковий вантаж. Тензор інерції обчислюється відносно загального ЦМ
за теоремою Гюйгенса–Штейнера.

### 3.7 Конструкція променя
Розрахункова схема — консольна труба (Ейлер–Бернуллі), защемлена в затискачі.

- Згин: M = T L, σ = M c / I.
- Кручення: τ = Q c / J.
- Еквівалентне напруження: σ_vm = √(σ² + 3τ²).
- Допустиме напруження: σ_доп = σ_ult · k_joint / SF, де k_joint — ослаблення в затискачі (концентрація напружень, зминання).
- Прогин кінця: δ = T L³ / 3EI; нахил мотора: θ = T L² / 2EI.
- Перша власна частота (метод Релея): f_n = (1/2π) √(3EI / L³ / (m_tip + 33/140 m_arm)).

Верифікація — МСЕ з балковими елементами Ерміта, узгодженою матрицею мас і дослідженням збіжності.

**Потенційно критичні ділянки:**
1. Корінь променя в затискачі: максимальний момент, концентрація напружень, зминання тонкостінної труби.
2. Кріплення мотора: кручення, вібрація.
3. Вузол кріплення вантажу і шасі: посадковий удар.

### 3.8 Посадка
n_land = 1 + v² / (g s), де s — хід шасі; F = n_land · W.

## 4. Критерії допустимості (обмеження)

Усі обмеження записано в нормованій формі g_j = попит/ресурс − 1 ≤ 0.

| # | Обмеження | Попит / ресурс | Залежить від m_p |
|---|---|---|---|
| 1 | Запас тяги | k_TW · max T_i / T_max | так |
| 2 | Тривалість польоту | t_min / t | так |
| 3 | Струм мотора | I(k_cont · max T_i) / I_cont | так |
| 4 | Температура мотора | ΔT_w / (T_max,w − T_amb) | так |
| 5 | Струм батареї | I_bat · k_cont^1.5 / (C · Q) | так |
| 6 | Міцність променя | σ_vm(k_dyn T_max) / σ_доп | ні |
| 7 | Нахил мотора | θ(T_max) / θ_max | ні |
| 8 | Резонанс | res_margin / min\|f_1P,2P − f_n\| / f_n | так, **немонотонно** |
| 9 | Керованість по рисканню | α_min / α_z | так |
| 10 | Посадка | n_land W / F_доп | так |

Обмеження 6–7 не залежать від m_p, бо мотор не може створити тягу, більшу за T_max.
Вони дають перевірку «пройшло / не пройшло», а не межу навантаження.

## 5. Постановка задачі граничного навантаження

```
m_p* = sup { m_p ≥ 0 :  g_j(x, m_p) ≤ 0,  j = 1..10 }
```

Розв'язок шукається в два кроки:
1. Сканування сітки m_p ∈ [0, m_hi]. Воно знаходить усі зміни знаку, включно з немонотонним резонансним обмеженням,
   і нижню межу допустимої області m_min, якщо вона є.
2. Бісекція до заданої точності.

Окремо для кожного обмеження обчислюється його власна межа m_j. Активним є обмеження з мінімальною m_j.
Для монотонних обмежень результат перевіряється незалежним методом (fzero).

**Невизначеність.** Monte Carlo з трикутними розподілами (lo, nom, hi) для епістемічних параметрів.
Експлуатаційні параметри фіксуються на гіршому випадку. Вибірки з фізично неправдоподібним FM > 0.85 відкидаються,
а їх частка свідчить про несумісність незалежно заданих діапазонів C_T і C_P.
Рекомендоване значення — P5 розподілу m_p* у гірших умовах.

**Альтернативні методи невизначеності** (`solver/uncertainty_methods.m`, розділ 5а звіту) - порівнюються на тих самих
параметрах: інтервальний аналіз (гарантований діапазон без розподілів, з перевіркою вершинами; окремо без немонотонного
резонансу), FOSM (дисперсія через градієнти), FORM (найімовірніша точка досягнення цілі, HL-RF), квазі-MC на послідовності
Халтона та аналітична формула для домінуючого обмеження запасу тяги m_p* = 4 T_max / (k_TW g r) - m_порожня.
Обмеження: FOSM не бачить зламів min() і резонансу; Халтон погіршується при розмірності понад ~20 (скремблювання лише
зсувом); інтервальна межа - найменше знайдене значення, а не доведений глобальний мінімум.

**Чутливість:**
- локальні еластичності E = (∂y/∂x)(x/y) центральними різницями ±1%;
- торнадо-діаграма (OAT по всьому діапазону);
- кореляція Спірмена за результатами Monte Carlo.

## 6. Розділення характеристик за рівнем доказовості

| Рівень | Джерела параметрів | Статус результату |
|---|---|---|
| 3 | measured, design, requirement, constant | Підтверджено / задано |
| 2 | datasheet | Розрахункова оцінка |
| 1 | assumed | Гіпотеза |

Кожен вихід успадковує **найнижчий** рівень серед параметрів, до яких він чутливий (|E| > 0.01).
Залежності визначаються автоматично з матриці еластичностей.

## 7. Що неможливо встановити без експерименту

C_T, C_P (і отже FM) — залежать від конкретного пропелера і числа Рейнольдса.
R_th мотора під обдувом. Реальна напруга і ємність батареї під струмом польоту.
Внутрішній опір пакета. Жорсткість і міцність труби (укладка волокон).
Коефіцієнт ослаблення в затискачі. Маси за CAD.

## 8. Межі застосовності

- Статичне висіння без вітру. Поступальний політ, вітер і граунд-ефект не враховано.
- Статичні C_T, C_P. Взаємовплив роторів і рами (обдув рами, blockage 5–10%) не враховано.
- Лінійна пружність, малі прогини. Немає втоми, вібраційної міцності, крихкого руйнування композиту.
- Усталений тепловий режим. Не враховано нагрів ESC і батареї.
- Батарея з постійною напругою і ємністю.
- Динаміка керування (смуга пропускання, насичення ШІМ) замінена запасом тяги k_TW.

## 9. Методика експериментальної перевірки

1. **Стенд тяги** (мотор + ESC + пропелер, тензодатчики сили й моменту, тахометр, ватметр).
   Вимірюються T(n), Q(n), I(V, n). Звідси C_T, C_P, FM, Kv, R_m, I0 і T_max при V_cell_oc.
2. **Тепловий тест на стенді**: тривала робота на тязі висіння × k_cont, термопари на обмотці. Визначається R_th.
3. **Батарея**: розряд струмом польоту з логуванням напруги та температури. Визначаються Q, V_cell_oc, R_pack (DC-IR).
4. **Конструкція**: триточковий вигин зразка труби (E, σ_ult); статичне навантаження променя у штатному затискачі
   до руйнування (k_joint); модальний тест (удар молотком + акселерометр) для f_n.
5. **Зважування** зібраного апарата (m_empty) і визначення ЦМ на трьох опорах.
6. **Прив'язне випробування** з вантажем, що зростає ступенями (0.5 кг): лог газу, струму та температури.
   Критерій — газ висіння ≤ 1/k_TW, температура в нормі.
7. **Політ на тривалість** з номінальним вантажем: перевірка t ≥ t_min з резервом.

Після кожного вимірювання оновлюються `nom/lo/hi` і `src = 'measured'`. Звіт автоматично підвищує рівень доказовості
і звужує діапазони невизначеності.
